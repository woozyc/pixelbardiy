# HaloStudio 2.8.0

- 支持 Windows 版 Apple Music 自动歌词：通过系统媒体会话获取歌曲与进度，匹配在线歌词或导入 LRC；不直接读取 Apple Music 内置歌词。网易云原有同步方式保留。
- 新增监控和可爱时钟主题、显存与频率指标、RTSS 帧率支持；修复后台监控采样，保留旧主题功能与设置。
- 主题分为监控、时钟两组，默认各展示三个，箭头展开更多；监控优先显示离子仪表、雷达终端、琥珀音响。
- TempoHub 官方配色收到主题配色底部，默认折叠。设置重整为「显示内容」与「画面样式与动效」。
- 界面与 README 明确播放器支持范围；音量律动目前仍仅采样网易云。

下载并完整解压 HaloStudio-CSharp-2.8.0-win64.zip，退出旧程序后运行 HaloStudioNet.exe。已有用户请保留自己的 runtime 目录（设置、歌词缓存、MCU 验证记录）；分发包不含个人记录。Windows x64，已包含 .NET 10 运行时。

本次仅更新电脑端，不修改 MCU 或刷写固件。原有设备适配与固件风险说明仍适用，请阅读 README。

本机验证：1199 项自测及 36 组布局检查通过；实际启动、显示传输与 CPU 温度采集正常。发布流水线另对解压后的应用包执行校验、自测与遥测联调。Apple Music 的歌词匹配和进度可用性取决于歌曲及播放器版本。
